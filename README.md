# Four-Dimensional Connectedness Loci

Research and interactive mathematical atlas by **Bernat Espigulé**, Universitat de Girona.

## Companion manuscript

**Four-Dimensional Connectedness Loci and Structural Stability for Planar Binary Similarities** (2026).

This repository accompanies the manuscript, Barcelona Mathematical Days poster, and real-time explorers for planar binary self-similar sets. An arXiv identifier will be recorded after public announcement; none is assigned here.

The three plane-orientation types are direct/direct (DD), direct/opposite (DO), and opposite/opposite (OO). The four-family visual comparison selects DD(1,0), DD(1,1), DO(1,0), and DO(1,1), using exterior coefficients of modulus greater than one. The reflected DD(0,1) presentation is not duplicated. Colour records contraction weight in three-dimensional projections.

## Evidence and reproducibility

Exact theorems, verified finite certificates, and finite numerical displays are distinct. Finite survival is not a connectedness proof. Unpainted stable-slice regions have no assigned membership classification. A hole in a slice or projection does not establish a bounded complementary component in four dimensions.
